# Sistema de Organización de Torneos (Frontend)

Proyecto frontend en React + Vite + TailwindCSS que simula una plataforma moderna de torneos (estilo esports). Contiene páginas: Dashboard, Torneos, Crear Torneo, Ranking, Bracket y Perfil.

Instalación:

```bash
npm install
npm run dev
```

Estructura principal:

src/
- components/
- data/
- layouts/
- pages/
- services/
- styles/

Notas:
- Los datos están simulados en `src/data/`.
- Los services (`src/services/*`) devuelven promesas como si fueran llamadas a una API.
- Diseño: TailwindCSS con tema oscuro y estilo gaming.
